Standalone Activity — behavior from the executable spec

A Canvas Commons animation of the Standalone Activity (SAA) state machine. Nothing here is hand-authored behavior: an executable imports the Go spec (saaspec.Model), walks its reachable state space, runs directed traces, and emits the data that drives this animation.

What the spec says

11statuses
59status transitions
82rejections
10directed traces

Traces shown

  • Happy path
  • Start delay defers the first dispatch
  • Retryable failure, then success
  • Retries exhausted
  • Pause while scheduled, then unpause
  • Pause takes effect on the retry
  • Cancel a running attempt
  • Reset applies when the attempt ends
  • Start-to-close timeout retries
  • Terminate

How it is generated

  • saaanim (Go) imports saaspec and derives the graph, rejections, and traces by executing Model / Initial / ExpectedDescribe / ExpectedHeartbeatFlags — it encodes no product behavior of its own.
  • It emits a typed TypeScript data module.
  • A presentation-only Canvas Commons scene renders whatever that data contains; the rendered scene is encoded to the video above.
Source spec: chasm/lib/activity/saaspec/model.go. Built with Canvas Commons.
